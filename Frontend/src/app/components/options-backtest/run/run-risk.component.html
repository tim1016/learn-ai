Definitions & assumptions

Sortino uses the same daily return series as Sharpe and a zero downside target. Downside squared returns are averaged over all observations. No downside makes Sortino unavailable. Volatility uses sample standard deviation and the same calendar annualization. Means describe the recorded path; they are not forecasts. Rolling windows overlap. Square-root annualization does not adjust for serial correlation in daily returns. Concentration can exceed 100% when other sessions lose money.

The distribution uses ten equal dollar intervals, each including its lower bound; only the final interval includes its upper bound. A constant sample has one interval.
