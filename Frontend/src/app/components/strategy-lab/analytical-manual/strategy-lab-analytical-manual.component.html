Strategy Lab manual

Read the evidence before reading the formula.

Results can share a label while using different producers. This manual starts with the run's recorded context, then exposes the documented calculation contract.

Read a run in this order

  1. Confirm the run inputs, data window, fills, costs, and producer.
  2. Read return and drawdown together.
  3. Check the number of observations before relying on a ratio.
  4. Use the evidence grade as product policy, not proof of deployability.
  5. Investigate unavailable evidence instead of treating it as zero.
