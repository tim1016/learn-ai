Every account switch

Switch between Paper and Live

Keep one saved profile for each account. Then use the same four steps in either direction.

  1. 1
    Stage the destination profile

    Under Profiles, choose Stage beside Paper or Live.

  2. 2
    Record Apply

    Confirm the Staged card is correct, then choose Apply staged revision.

  3. 3
    Restart the worker

    Refreshing or reopening the browser does not apply the change.

    {{ restartCommand }}
  4. 4
    Verify before deploying

    Check Effective now and the top ALPACA banner for the intended mode and account.

Live → Paper: use the four steps above; no clean-slate script is needed.

Paper → Live: first clear Paper exposure, then use the guarded handoff script below.

A profile switch never retargets, arms, or launches an existing bot. Deploy bots only after the intended account is visibly effective.
