Broker connection

Which Alpaca account this installation connects to, and how to change it

The broker connection chooses which Alpaca account this installation talks to, for example switching the whole installation from a paper account to a live one. A change is staged, applied and takes effect when the worker restarts; it never moves bots or money, and no credential is ever entered here.

It is not the account stage. The account stage (Shadow → Review → Live, shown on the Live account) decides whether a connected live account trades with simulated fills or with real money. Both are sometimes called “going Live”; only the account stage lets a Live account spend real money.
