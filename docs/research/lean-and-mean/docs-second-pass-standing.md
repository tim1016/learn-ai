## How each doc was judged

- **keep** — the doc holds something code cannot: a decision and its why, an operator procedure, an outside fact (vendor behavior, entitlement limits, exchange rules), an accepted numerical divergence, or intent for work an open issue is still building. The row names that thing.
- **slim** — some sections restate code. The row names those sections and the code that says them.
- **cut** — everything in it is restated by code, tests, a fixture attribution or an ADR. The row names where, as `file:line`.
- **"ADR owed"** marks a kept why that belongs in an ADR in force rather than a loose doc. It does not block the slim; the list is in its own section below.
- **Evidence.** For each doc: its headings and size; its inbound references from code, tests and link-checked docs (`git grep` on the basename); for math notes, the fixture attribution, the code's provenance block and the parity test; and the other kill lists' verdicts on the code each doc describes (all 31 lists on `origin/research/lean-*`). Bodies were read where the headings did not settle it. Rows judged on headings and first-pass evidence alone say so, and are listed again under **Not reviewed**.
- **◇ volatility.** The IV solver, surface fitting, VIX-style IV30, RV, basis conversion, put-call-parity forwards, vega and `iv30_health` code stays. Their docs still stay only for what code cannot say. The code's provenance blocks already carry most formulas and citations (`app/volatility/basis.py:3-6`, `fitting.py:5-8`, `iv30_health.py:3-6`, `iv_provenance.py:3-6`, `price_normalization.py:3-6`, `services/bs_greeks.py:3-6`, `engine/edge/vrp.py:3-6`).
