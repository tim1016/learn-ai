# Bot page redesign: mockups

Throwaway research branch. Never merged.

Clickable mockup and screenshots for the bot page redesign PRD. It depends on
#2639 (strategy view and Dark Bright Gate) and replaces #2639's frontend
presentation.

- `mockup.html`: download it and open it in a browser. It needs internet for the
  icons and the mono font. Switch layouts with ‹ › or the arrow keys, switch bot
  states with Running / Finished / Ended holding, and open Notes for the change list.
- `01`–`07`: the chosen layout (A, the 6·3·3 grid with event lanes under the chart)
  at 1440×900.
- `08`, `09`: the alternatives that were not chosen.

Data: bot `spy-ema-20260930-1430` on Sep 30 2026, using real Polygon bars.
The EMA and RSI values and the gate shading were computed in the browser for
the mockup. The build shows the bot's own recorded values (#2639 D1).
"Ended holding" adds one made-up manual buy.
