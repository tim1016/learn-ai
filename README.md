# learn-ai

A personal project for learning quantitative trading: I port trading math
from reference code and check that my version gives the same numbers.

It isn't a product and isn't maintained for anyone else. The issues and pull
requests here are my own working notes, and I'm not taking contributions.

There's no license, so you're welcome to read the code, but it isn't licensed
for reuse. Code vendored under `references/` keeps its original license.

Nothing here is financial advice.
